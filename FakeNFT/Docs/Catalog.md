# Эпик: Каталог

Декомпозиция эпика «Каталог» на три подфичи по [ТЗ](../Readme.md#каталог): **сетевой слой**, **экран каталога** и **экран коллекции NFT**.

**Общая оценка:** ~24 часа
**Архитектурный паттерн:** MVVM
**Технологии:** UIKit, URLSession, GCD, DispatchGroup

Используется существующая инфраструктура стартового проекта: `NetworkClient`, `NftService`, `ServicesAssembly` и `NftDetailAssembly`.

## Критерии готовности эпика

### Экран каталога

* [ ] `UITableView` отображает обложку, название и количество NFT в коллекции
* [ ] Во время сетевого запроса отображается индикатор загрузки
* [ ] Работает сортировка по названию и количеству NFT
* [ ] Выбранная сортировка сохраняется в `UserDefaults`
* [ ] Значение сортировки по умолчанию — по количеству NFT
* [ ] При ошибке загрузки отображается сообщение
* [ ] Нажатие на ячейку открывает экран коллекции

### Экран коллекции NFT

* [ ] Отображаются обложка, название, описание и автор коллекции
* [ ] Сайт автора открывается в `WKWebView`
* [ ] NFT загружаются параллельно через `DispatchGroup`
* [ ] `UICollectionView` отображает NFT в три колонки
* [ ] Ячейка содержит изображение, название, рейтинг и цену в ETH
* [ ] Работает добавление и удаление NFT из избранного
* [ ] Работает добавление и удаление NFT из корзины
* [ ] Для NFT в корзине отображается иконка крестика
* [ ] Нажатие на NFT открывает готовый экран деталей NFT

### Архитектура

* [ ] View, ViewModel и Service разделены
* [ ] ViewModel не содержит UIKit-кода
* [ ] ViewController не выполняет сетевые запросы и сортировку
* [ ] Зависимости передаются через `Assembly`
* [ ] ViewModel связывается с View через замыкания
* [ ] Для сети используется существующий `NetworkClient`
* [ ] UI обновляется только в главном потоке
* [ ] Swift Concurrency не используется
